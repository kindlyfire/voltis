# Mobile app

The Android app reads comics from your Voltis server. Your reading progress
syncs with the web app, and chapters can be downloaded to read offline. Books
aren't supported yet.

<a href="/voltis-1.0.0-beta.3.apk" download><strong>Download
voltis-1.0.0-beta.3.apk</strong></a>

The app is not on Google Play. To install it, open the APK on your phone and
allow your browser or file manager to install unknown apps when asked.

## Features

- Fully native app
- Feature-parity with the web reader for comics/manga/webtoon (no books yet)
- Offline downloads, including "keep next X unread entries downloaded"
- Offline progress tracking

Books are not supported yet, and the mobile app does not have the management
features of the web app (primarily admin settings).
